Project Overview

효율을 확보할 수 있는 AI 워크 플로우 구축

기획/디자인 후 F/E 개발 및 디자인 QA 진행 시 필요 이상의 시간이 지속적으로 소모되고 있었습니다.
이러한 비효율적인 부분을 최소화 하기 위해 디자인 시안을 정확하게 학습하고
바이브 코딩 시 개발의 정확성을 확보하는 것이 필요하다고 판단했습니다.

Fluid Main Functions

플루이드 주요 기능

디자인 시스템이 있어도 이를 기반으로 구현해주지 못하는 부정확함으로 인해
이를 메우기 위하여 가장 작은 단위부터 터치해야 하는 비효율적인 문제를 해결하고자 하였습니다.
시스템 학습부터 개발 산출물 까지의 체계를 단축할 수 있는 방향으로 기능을 채택 했습니다.

Vibe coding workflow

실제 화면 구현 시 작업 과정

플루이드를 통해 화면을 선학습을 진행 후 바이브 코딩을 진행합니다.
기존의 ‘Talk to figma’ MCP를 통해 진행했을 시 화면의 구성부터 학습을 시작했던 것과 달리
개발 시작점이 화면의 구성요소를 명확히 인지하고 있는 상태에서 시작하여 보다 정확성 높은 산출물을 작업합니다.

Project Result

비효율적으로 소요되던 시간을 획기적으로 줄일 수 있도록 하였습니다.
