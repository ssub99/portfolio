Project Overview

서비스 개선방향 설정 및 서비스 사용행태 분석

가계 기입 시 수기 기입으로 인한 번거로움을 해소해줄 기능으로
문장형 기록 생성을 만들었지만 저조한 이용율을 보이고 있었습니다.
간편생성 비율을 확보하기 위해 SMS/알림 수신형 기록 기능을 만들어 배포하였으나 이용자는 극소수에 불과했습니다.

Discover the Problem

알림 카드 및 공지사항이 유효하게 작동하지 않음을 확인

SMS/알림 수신 기능을 사용자들에게 안내하기 위해 기존에 사용했던 공지사항 기능과
알림 카드를 2주동안 노출하였으나 이벤트로 추적했을 때 극소수의 사용자만이
기록 수신을 사용하고 있는 것을 확인할 수 있었습니다.

Defining Hypotheses

기능 업데이트의 인지 부족으로 인할 것이라고
가설 설정하고 A/B 테스트 진행

단일 개선을 배포하여 전혀 작동하지 못했던 부분을 좀 더 임팩트 있게 전달하기 위해
신규/기존 사용자 모두에게 온보딩과 체험하기를 노출하고 세션 리플레이로 확인 시 사용했던 패턴대로만 사용하는 것을 고려하여
광고 소재를 SMS/알림 수신 기능이 드러날 수 있도록 변경하여 추가적으로 광고를 집행 하였습니다.
